# Privacy Policy for Draik Discord Bot

**Effective Date:** [24/March/2026]

This Privacy Policy describes how Draik ("Draik", "we", "our", or "the bot") collects, uses, stores, and protects data when you use our services.

---

## 1. Consent

By inviting or using Draik in your Discord server, you agree to this Privacy Policy and the data practices described below.

---

## 2. Data We Collect

Draik only collects data that is necessary for its features to function correctly. The types of data collected are listed below:

---

### a) Discord Identifiers

We collect and store the following identifiers:
- User IDs  
- Server (Guild) IDs  
- Channel IDs  
- Message IDs  

These identifiers are used to:
- Link data to specific users or servers  
- Store configurations and preferences  
- Execute commands and maintain feature functionality  

> Draik does NOT collect personal information such as email addresses, passwords, or private account details.

---

### b) Server Configuration Data

Draik stores configuration data set by server administrators. This includes:

- Automod rules and filters  
- Autoresponder triggers and responses  
- Autoreactor configurations  
- Antinuke protection settings  
- Ticket system configurations (roles, categories, permissions)  
- Vanity role configuration  

This data is required to ensure that Draik behaves according to each server’s custom setup.

---

### c) Message Content Processing

Draik may process message content **in real-time** for specific features, including:
- Automod filtering  
- Autoresponder triggers  
- Autoreactor responses  

Important:
- Message content is **NOT stored permanently**  
- Content is only processed temporarily to execute commands or triggers  
- No message content database is maintained  

---

### d) Message Tracking Data

Draik includes a message tracking system that:
- Stores the **number of messages sent by users**  
- Does NOT store message content  

This is used for:
- Activity tracking  
- Moderation insights  
- Feature-related analytics  

---

### e) Invite Tracking Data

To provide invite tracking functionality, Draik stores:
- Invite usage data  
- Information about which user invited another user  

This allows server administrators to monitor server growth and user invitations.

---

### f) Presence-Based Vanity System

If enabled by server administrators:
- Draik checks user presence (e.g., custom status text)  
- This is used to assign vanity roles automatically  

Important:
- Presence data is **not stored permanently**  
- It is only checked when required for role assignment  

---

### g) Ticket System Data

For ticket system functionality, Draik stores:
- Ticket creator (user ID)  
- Ticket channel ID  
- Timestamps and status (open/closed)  
- Ticket configuration settings  

This ensures proper ticket management and system operation.

---

## 3. Purpose of Data Collection

All collected data is used strictly for:
- Operating and maintaining Draik’s features  
- Storing server-specific configurations  
- Enabling moderation, automation, and tracking systems  
- Improving stability and performance  

We do NOT use data for:
- Advertising  
- Selling or sharing with third parties  
- User profiling  

---

## 4. Data Storage & Security

- Data is stored using secure database systems (e.g., MongoDB)  
- Access is restricted to authorized systems only  
- We implement standard security measures to protect stored data 

---

## 5. Data Sharing

Draik does NOT:
- Sell user data  
- Share data with third parties  
- Provide data to advertisers  

All data remains internal and is used only for bot functionality.

---

## 6. Data Retention

- Data is retained only as long as necessary for feature functionality  
- Data may be automatically removed if no longer required  
- Server owners may request deletion of their server data  

---

---

## 9. Use of Discord Intents

Draik uses certain Discord Gateway Intents to operate its features:

- **Guild Members Intent**  
  Used for invite tracking, moderation systems, and ticket management.

- **Message Content Intent**  
  Used for automod, autoresponder, and autoreactor systems that require reading message content to function.

- **Presence Intent (if enabled)**  
  Used for vanity role systems based on user status.

These intents are required for Draik’s functionality and are only used within the scope of its features.
